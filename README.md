# Aybüke Yaren Kolcu Portfolio

This repository contains a personal portfolio website built with Next.js and Tailwind CSS. It showcases cloud engineering experience, services, resume details, and a markdown-powered blog.

## Features

- Personal portfolio layout for a cloud engineer and developer
- Work section with role, dates, accomplishments, and project summaries
- Service listing for cloud engineering, DevOps, and backend support
- Resume section with education, certifications, and skills
- Built-in blog support using markdown files
- Custom cursor and dark mode support
- Simple content editing via the dashboard interface

## Sections

- Header
- Work
- Services
- About
- Resume
- Blog

## Getting Started

1. Clone the repo
2. Install dependencies:

   `npm install`

3. Run the development server:

   `npm run dev`

4. Open `http://localhost:3000` in your browser

## Deployment

This project can be deployed to any Next.js-compatible host such as Vercel, Netlify, or Cloudflare Pages.

### Example deployment flow

1. Push the repository to GitHub
2. Connect the repo to your preferred host
3. Use `npm run build` and `npm start` for production
